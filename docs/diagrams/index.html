Architectural Tenets

Core System Guarantees

1. Code-Isolated Deterministic Scoring

The 0–24 FFMI scoring and tier classification engine is 100% pure Python with zero LLM or ML dependencies. Auditable, versioned, and perfectly reproducible.

2. Offline-First Field Operation

Farmer PWA operates seamlessly in zero-connectivity rural areas with a cache-first Service Worker, IndexedDB local persistence, and instant client-side calculations.

3. Governed Batch ML & MLOps

Celery Beat periodic batch jobs handle population segmentation, 12-month trajectory default risk forecasting, and evidence anomaly scanning with MLflow registry tracking.

4. Ground-Truth Evidence Verification

FFF Verified accreditation captures GPS coordinates, EXIF timestamps, and ground photography, protected by automated anomaly detection algorithms.
